# Andrins Packs

Fabric-Mod für **Minecraft 26.3** (NoRisk Client) mit **36 Ressourcenpaketen**, die du im Spiel einzeln an- und ausschalten kannst.

## Download
👉 **[Neueste Version herunterladen](../../releases/latest)**: die `.jar` unter „Assets“.

## Installation
1. **Fabric API** für 26.3 installieren.
2. `andrins-packs-x.x.x.jar` im NoRisk Client zum 26.3-Profil hinzufügen.
3. Im Spiel **K** drücken → Pack-Menü.

## Pack-Menü
- Suchfeld, Kategorien (Kampf, Welt, Lila, Redstone, HUD, Streamer, Spass), Pack-Bilder, Scrollliste
- „Alle an“ / „Alle aus“ wirken auf die angezeigten Packs
- Taste oben rechts änderbar

## Eigene Packs
- **Spatula**: Dreizack wird zum Pfannenwender, auch geworfen und im Boden
- **Anti-Leak Zufall**: Stein, Deepslate, Bedrock und Erze zeigen zufällige Blöcke (gegen Base-Leaks im Stream)

## Hinweis
Die enthaltenen Ressourcenpakete stammen von ihren jeweiligen Autoren (siehe Pack-Beschreibungen). Nur für privaten Gebrauch.
